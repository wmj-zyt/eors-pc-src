软件依赖：Graphviz图形可视化工具安装步骤
1. 打开Graphviz的官方下载界面
Windows
  • Stable Windows install packages, built with Microsoft Visual Studio 16 2019:
  • graphviz-12.1.2
  • graphviz-12.1.2(64-bit) EXE installer [sha256]
  • graphviz-12.1.2(32-bit) EXE installer [sha256]
  • graphviz-12.1.2(64-bit) ZIP archive [sha256] (contains all tools and libraries)
  • graphviz-12.1.2(32-bit) ZIP archive [sha256] (contains all tools and libraries)
2. 选择适合你的Windows版本(通常是64位)的安装程序并下载。
3. 双击下载的.exe文件，遵循安装向导的指示完成安装过程。注意在安装过程中勾选"自动添加到环境变量"。
4. 若在上一步中未选择添加到环境变量，则在电脑的"编辑系统环境变量"窗口将Graphviz的bin目录添加到Path环境变量中，点击确定保存修改。
5. 重启计算机使环境变量生效。
6. 打开电脑上的cmd命令提示窗口，输入dot -v并按Enter键，如果Graphviz已正确安装并配置，应该会显示Graphviz的版本信息。
Microsoft Windows [版本 10.0.19045.4894]
